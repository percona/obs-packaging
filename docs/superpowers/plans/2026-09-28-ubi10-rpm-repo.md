# UBI 10 RPM Build Repository Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the `UBI_10` RPM build repository to every OBS project that already builds for `UBI_8` and `UBI_9`, so that every package green on `UBI_9` is also green on `UBI_10` for x86_64 and aarch64.

**Architecture:** Pure packaging-config change. One repository block in `root/project.yaml` is inherited by the whole tree; the two projects that opt out of inheritance and declare their own UBI repositories (`_shared/extras`, `16/tde`) get an explicit block; prjconf blocks that exist for `RockyLinux_10` are widened to `UBI_10`; four `package.yaml` files that disable `UBI_9` also disable `UBI_10`. Nothing in `percona_obs/`, `.github/` or `root/ppg/releases/` changes.

**Tech Stack:** YAML packaging tree under `root/`, `percona-obs` CLI (`project config`, `project verify`), pytest suite in `tests/`, OBS on `obs.pg.labs.percona.com` via the `labsmain` profile.

**Spec:** `docs/superpowers/specs/2026-09-28-ubi10-rpm-repo-design.md`

## Global Constraints

- Work only in the worktree `.claude/worktrees/ubi10-repo` (branch `ubi10-repo`, based on `percona/main`). Never `cd` to the primary checkout.
- `venv` and `.profile` in the worktree are symlinks to the primary checkout's. `venv/bin/python -m percona_obs …` is the CLI. All `project config` calls below need `-P labsmain --offline`; the `labsmain` profile slices output to `UBI_*`/`ubi*`/`images` repositories, so `RockyLinux_*`, Debian and Ubuntu repos are expected to be absent from its output.
- The `UBI_10` repository block is byte-for-byte the `UBI_9` block with `9` → `10`, in the same path order (`common:deps:build`, EPEL, `RedHat:UBI-10/standard`, `RockyLinux:10/devel`), `archs: [x86_64, aarch64]`. Same rule for the opt-out projects: copy their own `UBI_9` block.
- prjconf for `UBI_10` = the three `RockyLinux_10` settings from `root/ppg/staging/subprojects.yaml` (`Prefer: selinux-policy-targeted`, `Prefer: hdf-libs`, `%__brp_check_rpaths %{nil}` macro). No `have choice` fixes up front.
- `package.yaml` rule: `UBI_10` mirrors `UBI_9`. Only the four packages with `UBI_9: false` get `UBI_10: false`. Do not copy `RockyLinux_10: false`.
- No changes under `root/ppg/releases/`, `percona_obs/`, `.github/`, `tests/`.
- Commits: `git commit -s`, no `Co-Authored-By` lines. Never `git push`, never `gh pr create`; the user does both after Task 5.
- After every task: `venv/bin/black percona_obs/ && venv/bin/pyright && venv/bin/pytest -q` must pass (369 tests at baseline; no Python changes expected, this guards the YAML through the config-merge tests).
